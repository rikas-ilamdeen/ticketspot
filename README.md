# TicketSpot: Real-Time Event Ticketing System

A real-time ticketing system that efficiently handles ticket releases by vendors (producers) and purchases by customers (consumers) using an advanced producer-consumer implementation. The system ensures thread safety, synchronization, and provides both CLI and GUI interfaces for ease of use.

---

## Features

- **Concurrent Ticket Management**: Handles real-time ticket release and purchase scenarios using multithreading.
- **Thread Safety**: Ensures efficient synchronization between producers and consumers.
- **Dual Interfaces**:  
  - **CLI**: For developers and automation testing.  
  - **GUI**: User-friendly frontend for real-time interaction.
- **Backend Integration**: Robust API support for ticketing operations.
- **Modern Tech Stack**: Built with Spring Boot for backend, Angular for frontend, and Java for CLI.

---

## Technology Stack

- **CLI**: Java  
- **Frontend**: Angular  
- **Backend**: Spring Boot
- **Database**: PostgreSQL
- **APIs testing**: Postman  

---

## Prerequisites

- Java 11 or higher
- Node.js (v16 or higher)
- Angular CLI (v14 or higher)
- Spring Boot (v2.7 or higher)
- PostgreSQL
